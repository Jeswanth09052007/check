# Quick repair walkthrough

1. **Profiles:** sign in as any demo role; click Profile, edit Major or Institution, save, close using Close/Escape.
2. **Provider uploads:** create a draft course → Videos → select course → upload WebM/MP4 → Materials → select same course → upload PDF. The uploaded items appear below the form. Use a title of at least three characters.
3. **Publish:** Courses → Submit review. Sign in as Payment Admin → Commercial → Review → Sanction & Publish. Return to Provider and focus the browser or wait for polling to refresh the status.
4. **Learner:** Learning → Enroll → Open course. Play the video, open PDF, mark each lesson complete. Course progress persists.
5. **Quizzes:** Provider → Quizzes → Create Quiz → add questions/options and select correct answers. Learner must enroll before taking the course quiz. Saved results appear for the provider.
6. **Challenges:** provider creates an assignment for a course; even students who enroll later receive it. Learner submits once; the owner approves and awards the configured points once.
7. **Trading:** search a symbol, place a small virtual buy, sell part, place a low limit buy and cancel it. Portfolio shows the remaining holding and all statuses. Watchlist Trade opens that symbol.
8. **Institutions:** User Admin → Commercial → Manage intake. SMTP is required for sending; without it the invitation link is still shown. Preview CSV before import. Download credentials before closing the result; emailing new credentials replaces earlier exported passwords.

Original navigation/CSS are retained. The trading screen and repaired controlled forms are the intentional functional changes. See VALIDATION_REPORT.md for verified checks and deployment limits.
